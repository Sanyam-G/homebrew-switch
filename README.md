# Homebrew tap for Switch

```
brew install --cask Sanyam-G/switch/switch
```

Use the fully qualified name (`Sanyam-G/switch/switch`). The short form `brew install --cask switch` resolves to NCH Switch Audio Converter in the official homebrew-cask, not this one.

Source: [Sanyam-G/switch](https://github.com/Sanyam-G/switch)
Site: [switch-dev.sanyamgarg.com](https://switch-dev.sanyamgarg.com)
